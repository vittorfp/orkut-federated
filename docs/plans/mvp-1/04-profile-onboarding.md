# MVP 1.4: Profile Onboarding

## Outcome

Invitation redemption establishes a stable handle and a useful public profile
that its owner can edit without changing identity.

## Subchunks

1. Handle grammar, normalization, reserved names, and confusable-name policy.
2. Onboarding fields inside the invitation redemption transaction.
3. Public profile query and route.
4. Owner-authorized profile edit service.
5. Accessible onboarding and edit UI.

## Gate

The handle cannot change, another user cannot edit the profile, reserved and
confusable handles fail, and unsafe profile text renders inert.

## Exclusions

Avatar upload remains in the media MVP.
